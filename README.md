# B Teck

A React + Vite website for B Teck.

## Scripts

- `npm run dev` starts the local Vite dev server.
- `npm run build` creates a production build in `dist`.
- `npm run preview` previews the production build locally.
- `npm run lint` runs ESLint.
- `npm run format` formats the project with Prettier.

## Project Structure

- `src/main.tsx` mounts the React app.
- `src/App.tsx` connects the page sections together.
- `src/sections` contains the main page sections like Hero, About, Services, Portfolio, and Contact.
- `src/components/layout` contains page layout pieces like Navbar and Footer.
- `src/components/shared` contains smaller shared visual components.
- `src/data/site.ts` contains editable website content, links, service lists, portfolio data, FAQs, and testimonials.
- `src/hooks` contains reusable React hooks.
- `src/styles.css` contains Tailwind and custom theme styles.
- `src/assets` contains image assets.
- `src/components/ui` contains reusable UI components.
